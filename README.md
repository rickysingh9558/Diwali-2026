# Happy Diwali 🪔

A standalone animated Diwali greeting page: fireworks, anar and chakri crackers, diyas, sky lanterns, rangoli and a marigold toran.

## Personalise a wish

Open the page, tap **Create Your Wish**, fill in the names and share the link. The wish travels in the link:

```
https://rickysingh9558.github.io/Diwali-2026/?to=Maa+%26+Papa&from=Ricky
```

Everything is a single `index.html` with no build step.
